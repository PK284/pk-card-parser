# Privacy Policy for PK Card Parser

_Last updated: 5 October 2026_

PK Card Parser is a personal project that I (Piyush Kumar) built and run only for myself. It is not offered as a service to anyone else.

## What the app accesses

The app asks for read-only access to my own Gmail account (the `gmail.readonly` scope) so it can find bank and credit card transaction emails and extract details such as the amount, merchant, date and card.

## How data is handled

- All processing happens locally on my own computer.
- The extracted data is stored in a local database on my own computer.
- The app does not send Gmail content, transaction data or tokens to any server, third party, analytics service or advertising network.
- The app does not share, sell or transfer data to anyone.
- The app does not use Gmail data to develop, improve or train any AI or machine learning model.
- The OAuth tokens are stored only on my own computer.

## Retention and deletion

Data stays on my computer until I delete it. I can disconnect the app at any time by removing its access at https://myaccount.google.com/permissions and deleting the local database.

## Google API Services User Data Policy

The use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
